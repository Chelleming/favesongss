# 🎵 Favorite Songs - Synchronized Lyrics Player

A collection of Python scripts designed to display synchronized time-coded lyrics and song playback in terminal output.

---

## 📄 Featured Track Scripts

- **`Nangiwan.py`** – Synchronized lyric display script for *Nang Iwan*.
- **`WhatifiCall.py`** & **`whatifiCall2.py`** – Synchronized lyric display script for *What If I Call*.
- **`song.py`** – Core time-delay lyric player script.

---

## 🛠️ Prerequisites

Make sure you have Python installed on your system:

- Python 3.x
